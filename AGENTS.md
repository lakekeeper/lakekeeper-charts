# AGENTS.md

## Changelog

- `charts/lakekeeper/Changelog.md` describes changes of the chart only: new values, changed defaults, template fixes, and breaking changes of the chart itself.
- For a Lakekeeper version bump, write one line with the new default versions and link the Lakekeeper and Lakekeeper Plus release notes. Do not copy their breaking changes or upgrade notes: they are kept and fixed only in the Lakekeeper repositories.

## Traps

- `charts/lakekeeper/README.md` is generated by helm-docs from `README.md.gotmpl` and `values.yaml`: edit those and regenerate it with `just update-readme`.
- After a template change, run `just test-render`; `UPDATE=1 just test-render` rewrites the golden files; review their diff.
- When you copy the OPA bridge policies from Lakekeeper, keep the chart's `import data.catalogs` and `trino_catalog := data.catalogs.trino_catalog` in `configuration.rego`: the chart generates the Trino catalogs from `OPABridge.catalogs`.
- A Lakekeeper version bump also changes the default image tags in `templates/_helpers.tpl`, not only `Chart.yaml`.
